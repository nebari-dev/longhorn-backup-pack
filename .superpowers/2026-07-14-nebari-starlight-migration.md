# Adopt @nebari/starlight Shared Theme Plugin

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace this repo's hand-rolled Nebari theme (vendored logo/favicon assets, custom `SocialIcons`/`RepoButton` override, vendored `nebari-tokens.css`/`starlight-theme.css`, and the React/Tailwind/shadcn scaffolding that supported it) with the `@nebari/starlight` Astro/Starlight plugin, matching the migration `nebari-dev/llm-serving-pack` already did in PR [#127](https://github.com/nebari-dev/llm-serving-pack/pull/127) (`docs: adopt @nebari/starlight shared theme plugin`) and PR [#132](https://github.com/nebari-dev/llm-serving-pack/pull/132) (`chore(docs): bump @nebari/starlight to 0.2.1`).

**Architecture:** `@nebari/starlight` is a Starlight plugin (`nebari()`) passed via `starlight({ plugins: [nebari(...)] })`. Its `config:setup` hook prepends its own `customCss`, `components` (SiteTitle/Head/Footer/ThemeSelect), and `social` (GitHub org link) entries onto whatever the consumer already has in those arrays/objects, then registers an `astro:build:done` integration that rewrites root-absolute links in built HTML to respect `base`. All theming (brand colors, self-hosted fonts, logo, favicon, footer) ships inside the plugin package — none of it needs to be vendored into this repo anymore.

**Tech Stack:** Astro 7, `@astrojs/starlight` 0.41, `@nebari/starlight` 0.2.1 (published, peer deps `@astrojs/starlight >=0.33.0 <1.0.0`, `astro >=7.0.6`).

### Task 2: Rewrite `docs/astro.config.mjs` to use the plugin

**Files:**
- Modify: `docs/astro.config.mjs`

**Interfaces:**
- Consumes: `{ nebari }` from `@nebari/starlight` (Task 1).
- Consumes: `remarkBaseLinks` from `./src/plugins/remark-base-links` (unchanged, not part of this migration).

- [ ] **Step 1: Replace the file contents**

```js
// docs/astro.config.mjs
import { defineConfig } from 'astro/config';
import starlight from '@astrojs/starlight';
import { nebari } from '@nebari/starlight';
import rehypeMermaid from 'rehype-mermaid';
import remarkBaseLinks from './src/plugins/remark-base-links';

export default defineConfig({
  base: process.env.BASE || '/',
  site: process.env.SITE,
  integrations: [
    starlight({
      title: 'Nebari Longhorn Backup Pack',
      description: 'Persistent volume backups on Nebari.',
      // Shared Nebari identity (brand colors, fonts, logo, favicon, footer, and
      // GitHub social link) comes from the @nebari/starlight theme plugin. On the
      // portal the header logo returns users to the pack catalog.
      plugins: [nebari({ logoHref: 'https://packs.nebari.dev/' })],
      sidebar: [
        { label: 'Introduction', slug: 'index' },
      ],
    }),
  ],
  markdown: {
    syntaxHighlight: { type: 'shiki', excludeLangs: ['mermaid'] },
    remarkPlugins: [[remarkBaseLinks, { base: process.env.BASE || '/' }]],
    rehypePlugins: [[rehypeMermaid, { strategy: 'inline-svg' }]],
  },
});
```

This drops: the `react()` integration, the `logo`/`customCss`/`components.SocialIcons` starlight options, and the entire `vite` block (the `@tailwindcss/vite` plugin and the `@/*` alias — both existed only to support the deleted React component stack).
